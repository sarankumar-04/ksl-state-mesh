Run in VS Code — Quick Start
1. Open ksl-fixed/ksl-core in VS Code
2. Make sure Java 17+ and Maven are installed. Run:
mvn spring-boot:run
3. Backend starts on localhost:8080
4. Open this ksl-dashboard.html file in your browser
5. Kafka is optional — set KAFKA_BOOTSTRAP_SERVERS env var, or it will run without events
Note: This UI calls localhost:8080 directly. If running a web server, ensure CORS is allowed (it is by default via CorsConfig.java). Auth: ksl-admin / ksl-sandbox-2024
